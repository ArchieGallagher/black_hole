## Overview

**Black Hole Sim** is a real-time renderer that simulates the gravitational bending of light (gravitational lensing) around a compact object (black hole). It computes geodesic trajectories of light rays passing near the black hole and renders realistic accretion disk visuals including gravitational redshift. A red sphere has also been implemented in order to better show the bending of the light.

## Features

- **Gravitational Lensing:** Accurate ray integration along curved spacetime geodesics.
- **Accretion Disk Rendering:** Temperature maps with gravitational redshift effects.
- **Interactive Camera:** Smooth orbit camera.
